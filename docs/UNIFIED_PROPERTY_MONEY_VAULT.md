# Voxel Vault Product Truth + Money Boundaries

Reviewed: August 29, 2026

## One simple product rule

Voxel Vault may put property, digital assets, wallets, and provider-backed positions in one interface, but it must never make different legal records look equivalent.

Use four public statuses:

- **LIVE DIGITAL** — works now for digital/map-backed features; no real-property rights are created.
- **DEMO** — sandbox only; no real money, security purchase, or property rights move.
- **PARTNER REQUIRED** — live execution only through an approved provider, eligibility checks, settlement, and verification.
- **TITLE REQUIRED** — real-property ownership changes only through normal closing and recorded title.

## Current live property product

The current VoxelPop property journey is:

```text
sign in
  -> authorized photo
  -> local VoxelPop preview
  -> source-backed 3D map
  -> private My World placement
  -> optional digital collectible checkout
  -> Vault
  -> optional separate Verify + Mint path
```

Creation does not require Meshy credits or a pre-generation payment.

The photo preview and mapped 3D record are intentionally different evidence layers. One image cannot verify unseen sides, exact dimensions, complete roof/facade geometry, title, ownership, or property value.

A purchased VoxelPop property collectible is a **digital asset only**. It does not create deed/title ownership, equity, rent rights, occupancy rights, a real-estate security, or guaranteed appreciation.

## $1.99 Property Demo

`/geo/slice` is a sandbox experience using a default **$1.99** anchor amount and fake demo USD.

It may show proportional property math and benchmark comparisons. It does not:

- transfer real funds;
- reserve property;
- create deed ownership;
- create an LLC interest;
- purchase a security;
- mint a real-estate security;
- create rent or occupancy rights.

A real small-dollar property investment may replace the demo only when the exact provider offering legitimately supports that amount and all required investor-eligibility, settlement, custody, disclosure, and position-verification gates are satisfied.

## Money and conversion rules

Keep these values distinct:

- **Settled USD** — cash only after the responsible provider reports settlement.
- **Estimated crypto value** — informational until an approved exchange/off-ramp settles a trade.
- **Estimated NFT value** — informational until a real marketplace sale settles.
- **Verified property/security position** — only after the responsible provider and reconciliation layer substantiate it.
- **Property goal/demo balance** — never presented as ownership or spendable customer cash.

Possible future provider-backed paths include:

```text
NFT -> marketplace sale -> settlement -> USD or crypto
crypto -> approved exchange/off-ramp -> settled USD
settled USD -> verified property/security offering -> provider-confirmed position
provider distribution -> settled proceeds -> optional user-authorized next action
```

No estimate becomes spendable money just because it appears in the same Vault screen.

## Regulated-role boundaries

### USD

Voxel Vault should not present itself as an FDIC-insured bank unless that exact status becomes true. Customer USD should use an appropriately disclosed banking/payment provider, with accurate deposit-insurance language for the actual structure.

Official reference: https://www.fdic.gov/resources/consumers/consumer-news/2023-07.html

### Crypto

Prefer user-controlled wallets unless an appropriately authorized custody/exchange/transmission provider is integrated. New York virtual-currency activity can require NYDFS licensing depending on the exact activity.

Official reference: https://www.dfs.ny.gov/virtual_currency_businesses

### Tokenized property / securities

Tokenization does not erase securities-law treatment. If a token represents a property-company share, REIT interest, note, or other security, the legal treatment follows the actual instrument and transaction.

Official references:

- https://www.sec.gov/newsroom/speeches-statements/corp-fin-statement-tokenized-securities-012826-statement-tokenized-securities
- https://www.sec.gov/resources-small-businesses/capital-raising-building-blocks/transactions-involving-crypto-assets
- https://www.sec.gov/rules-regulations/2026/03/s7-2026-09
- https://www.sec.gov/rules-regulations/2026/08/s7-2026-27

The August 18, 2026 Regulation Crypto Assets item is a proposal, not blanket authorization for a tokenized real-estate product.

## Public language

Preferred:

- `Voxel Vault`
- `digital property voxel`
- `digital collectible`
- `source-backed 3D map`
- `$1.99 Property Demo`
- `provider-backed investment`
- `verified position`
- `recorded title`
- `USD balance` only when the source/settlement status is clear
- `crypto wallet` when describing a wallet

Avoid implying Voxel Vault itself is a:

- bank;
- FDIC-insured institution;
- broker;
- securities exchange;
- crypto exchange;
- custodian;
- escrow service;
- deed registry.

## Production gates

Keep a real-money or regulated action disabled until the exact action has a verified owner and implementation, including as applicable:

- authentication and KYC;
- banking/payment-provider agreement;
- accurate insurance/disclosure language;
- compliant crypto custody/exchange/transmission path;
- approved NFT marketplace/off-ramp;
- verified property/security offering;
- investor eligibility;
- legal property/entity mapping;
- independent position reconciliation;
- explicit user authorization;
- ledger reconciliation and audit logging;
- fraud/transaction limits;
- emergency disable/kill switch.

## Final rule

**3D is the interface. Evidence is the authority.**

A photo, model, map marker, payment, NFT, wallet connection, Property Passport, or blockchain record never gains stronger legal meaning just because it is displayed beside another asset in Voxel Vault.
